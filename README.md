# PrintSaathi — USB Printer to WiFi & Bluetooth

Turn an Android phone + a USB printer into a **shared print server**. Everyone in the shop prints to it over **WiFi & Bluetooth** — plus scan, OCR, passport/photo prints and labels.

## Features

**PrintSaathi**
- Share any USB printer over **WiFi & Bluetooth** — print from every phone and PC
- Connect **USB / Bluetooth / WiFi** printers, with auto-detect
- Works with receipt (ESC/POS), label (TSPL, ZPL, EPL, CPCL), laser (PCL), driverless inkjet, Brother, HP and Canon
- **Scan**: preview + pick area, colour / grey / B&W, 100–600 dpi, PDF / JPEG / PNG
- **Scan to text (OCR)**
- **Passport & photo prints** with cut lines, and **AI background removal** (person or object) onto white / blue / grey
- **Tiny JPEG** (under 50 KB) for form uploads, with instant share
- **Print from anywhere**: a WhatsApp link + email-to-print
- Add new printers with driver packs — no app update

**Label Creator**
- Design labels: text, barcodes, QR
- Rulers, drag to place, fonts & bold, save & reopen
- Bulk print from Excel
- Integration API to call it from your own app (grocery / bakery / POS)
